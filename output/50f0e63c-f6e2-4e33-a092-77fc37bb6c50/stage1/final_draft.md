# 原创性与资源使用声明

## 一、原创性声明

本系统「多智能体软件开发系统」的需求定义、系统架构、协作流程设计、提示词设计、代码整合与验证均由本人独立完成。系统核心代码约 1180 行（Python 875 行、前端 305 行），其中代码草稿在多轮 AI 辅助下生成（详见第四节），全部逻辑经本人逐段阅读、修改、运行与验证后采用，不存在直接套用他人完整项目或抄袭他人代码的情形。项目中引用的开源组件已在第三节逐一列明，并遵守其各自的开源许可证。

## 二、使用的模型与数据

- **模型**：`qwen2.5:3b`（阿里通义千问开源模型，Apache-2.0 许可），以 Q4_K_M 量化权重（约 1.9 GB）部署于本地 **Ollama 0.40.5** 运行时。系统未调用任何闭源商业大模型接口。模型权重属第三方开源资产，非本人原创；本人的工作在于将其编排进多角色协作流程，并针对小模型设计判定与上下文约束。
- **数据**：系统**不使用任何外部训练集或评测数据集**。演示与验证所用任务描述（如「写一个判断回文字符串的 Python 函数」）由本人手工编写；运行期产生的协作历史仅存在于本地内存，不上传、不外传、不留存。

## 四、使用的 API 与外部工具

- **本地接口**：Ollama 运行时提供的 `POST /api/chat`（对话推理）与 `GET /api/tags`（模型列表校验），地址为 `127.0.0.1:11434`，仅在本机回环网络内调用。
- **本项目自定义接口**：`GET /`（页面）、`GET /api/roles`（角色定义）、`GET /api/status`（运行状态）、`GET /api/events`（SSE 事件流）、`POST /api/run`（提交任务），仅供本系统前端使用。
- **外部付费服务**：无。系统未接入任何需要密钥的第三方云服务、支付接口或商业数据 API。
- **外部工具与 AI 辅助**：代码的生成与调试**主要借助 sciencepal.ai 辅助完成**，用途包括生成函数与模块草稿、提示词调整建议、报错定位与重构建议。AI 生成内容均经本人审阅、改写并实际运行验证，未经运行验证的片段不予保留。系统设计与技术选型、验证方案的确定、测试执行与结论判断由本人完成。本文档的文字结构与技术事实由本人梳理确认，排版经 AI 助手协助完成。
